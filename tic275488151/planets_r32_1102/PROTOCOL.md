## Fixed estimator

Target KIC 10014894 / TIC 275488151.01. All available Kepler long-cadence quarters, final archive PDCSAP_FLUX, SAP_QUALITY == 0. Require finite TIME, finite positive flux and finite positive PDCSAP_FLUX_ERR; no clipping or additional detrending. Read headers/time/quality without accessing target flux first. BJD(TDB) = TIME + BJDREFI + BJDREFF. Process events within each quarter; do not bridge quarterly discontinuities. No period, epoch, duration or phase fitting.

Primary P = 3.0305267 d, T0 = 2454967.124438 BJD(TDB). Secondary T0 + 0.5007 P. At each predicted center, in-window |dt| <= 0.126 d. Baseline windows [-0.504,-0.252] and [+0.252,+0.504] d, endpoints included. Require at least 3 in-window points and at least 3 baseline points on EACH side. Predict every center whose in-window intersects the quarter's finite-time span; count invalid events without replacement. Quarters need not have equal weights.

Reproduce the r30 Kepler event estimator: ordinary least-squares baseline y=a+b dt in the two out windows. With xbar=(1, mean(dt_in)), mean-window fractional depth d=(xbar beta - mean(y_in))/a, positive for dimming. Require a>0 and a nonsingular baseline normal matrix. Variance v=s^2 [1/n_in + xbar (X'X)^(-1) xbar']/a^2. Here s^2 = max(sum(out residual^2)/(n_out-2), mean(PDCSAP_FLUX_ERR^2 over in and out)). This keeps the established local-residual estimator and adds a formal-error floor, never deflating errors. Baseline-normalization uncertainty is handled by the same first-order fixed-continuum convention as r30; the approximation and empirical validation are disclosed.

Stack all valid event depths with weights 1/v. D=sum(w d)/sum(w). Q=sum(w(d-D)^2). Error S=sqrt(max(1,Q/(N-1))/sum(w)); N<2 is invalid. Use the same rule for per-quarter descriptive stacks. No post-hoc rejection, offset adjustment or error deflation. Normal one-sided 99.7% limit U=max(0,D)+2.7477813854449926 S. The nonnegative-depth convention is conservative for negative measurements. Bar K iff finite primary U < 291e-6. Secondary is descriptive and uses the identical estimator; it cannot rescue a failed primary bar.

## Power design and stop rule

Exactly 200 injection trials and exactly 200 independent uninjected random-phase trials. Frozen seed 321102, NumPy Generator(PCG64). Draw uniform phases in [0,1), rejecting only circular phase distances <0.15 from either phase 0 or 0.5007. Generate all 200 injection phases first, then 200 null phases before any target flux access. Save the full design. No replacements for missing data or poor recovery; invalid trials count as failures.

For the gate only, remove original cadences with circular time distance <=0.126 d from either actual EB center BEFORE reading PDCSAP_FLUX, so the real in-window samples remain sealed. This uses time only. The estimator's in and baseline windows and point requirements are otherwise identical. Retained baseline samples may approach the real windows; their loss is reflected in the gate, with no phase substitutions. This OOT restriction is part of the requested away-from-EB-windows power design; real stacks later use every eligible cadence.

Into target's own retained PDCSAP inject a multiplicative 873e-6 box of full width 0.210 d at P_EB and T0+phase*P_EB. Cadence-center boxes (no exposure integration); leave errors unchanged, a conservative floor. Measure with the exact estimator above at the injected centers and the same +/-0.126 d window. The wider measurement window intentionally dilutes a 0.210 d box by about 0.210/0.252; do not correct this transfer or change the 5-sigma gate. Null phases use the original flux and same OOT restriction.

Gate PASS iff at least 190/200 injections have finite positive D/S >=5 AND at least 190/200 null phases have finite U<291e-6. Both denominators are always 200. Trials share real data and are an empirical phase ensemble, not independent datasets. Save event sufficient statistics and gate decision before opening real EB-window flux or computing either real stack. If either arm fails, write STATUS first line POWER_FAIL, leave both real ephemerides UNSCORED, and report. No retuning or second gate. If gate passes, read real eligible flux once, measure primary and phase-0.5007 secondary, save all events and descriptive per-quarter results, then independently verify.
