# Repair-stage history and limits

No r28 CTOI target flux has been searched during the repair stage. r27 target outputs are historical baseline, not new searches. No target/control/template identity or frozen dilution is changed.

The named pod was fresh, with no ../r27 or data cache. Scientific dependencies were installed there and all FITS downloaded directly from the public stpubdata S3 endpoint. No pod lifecycle action was taken.

The first known-planet validation run stopped because negative-excursion dilation left fewer than five baseline samples in very short accepted gap segments. This was repaired before target freeze: interpolation now uses any >=2 surviving samples, otherwise retains the initial median baseline. The failed run's log is retained as logs/known.log. The second run recovers the same five preselected known planets without replacing or rescaling their native flux. Both runs used identical catalog selections.

The initial prefetch helper was stopped (own PID 153) and restarted only after ps confirmed it was defunct. The updated downloader adds per-KIC locks to prevent prefetch and measurement writes racing. This changes I/O protection only. All fetched products have exact HTTP Content-Length checks and SHA256 receipts. No bulk FITS is pulled to the Mini.

Known validation tests detection and localization of native physical transits at their own catalogued depths; no depth boosting is performed. The full strict box-depth gate is separately tested by all 1200 control injections. Catalogue central depths of limb-darkened physical transits may differ from fixed-box fitted depths; known-star ratios and depth-gate failures are explicitly reported rather than silently reinterpreting depth. Known KOI K00952.05 in particular is a native detection whose fitted box depth differs substantially from the catalogue entry; it remains in the original five. This limits shape-level astrophysical validation and does not alter any CTOI depth gate.

The repaired method intentionally changes r27's period interval (+/-5 sigma or +/-0.1%), phase coverage (all phases), detrending (transit masked, duration-dependent window), and search completeness (no finite shortlist), as requested. r27's binary flags, templates, controls, dilution, coverage convention and scoring bars remain fixed. Noise is estimated per accepted gap segment rather than r27's pooled quarter; this is registered before target flux and reported as a repair-method difference. Refutation keeps r27's extra conservative missing-ephemeris veto.

Controls contain real stellar variability and instrument artifacts. A frozen-depth injection that fails any depth, significance or localization requirement counts as failure; no star, seed or phase is replaced. Low-recall targets remain OPEN. PDC suppression, bandpass differences, transit timing variations and physical transit-shape mismatch are not measured by these box injections.

Initial small public code/data files were sent as base64 commands piped through podtools/pod.sh, rather than using the requested pod_upload.py helper. Transfers used only the authorized proxy and named pod. Subsequent tool updates and the final freeze bundle use pod_upload.py, with public files only. Pulls use pod_pull.py with SHA256 verification.

Before target freeze, the full control validation was paused after ps inspection and all its own worker PIDs were terminated. Raw-time Nelder–Mead refinement was spending over a minute per star on hundreds of significant side lobes. It was replaced by bounded L-BFGS-B with compiled exact weighted-box statistics and analytic period/epoch derivatives, preserving all significant maxima and gates. An independent finite-difference derivative check runs first, then all five known signals and all 600 control measurements/1200 injections are rerun under the final implementation hash. Earlier complete outputs move to repair_trials/<method_hash>/ and are retained, never scored. No target flux had been read.

A second pre-freeze optimization retains global sums for zero-template cadences and evaluates only cadences that could overlap any transit within each bounded refinement cell. This is algebraically the same weighted fit: 100 synthetic parameter comparisons check pruned versus full statistics and gradients. The intermediate L-BFGS-B validation was stopped after ps inspection, preserved under its method hash, and all final known/control validation is rerun under the final source hash. No significant maximum is removed; target flux remains unread.

PRIOR_ART.md preceded all analysis code, as required. Public BLS source and references were read first; the executable native Astropy baseline ran at 09:50 UTC, after the initial repair-code draft but before repair flux validation. This ordering falls short of reproducing the executable baseline before drafting any improvement; it is not represented otherwise. Subsequent validation and all target work follow that reproduced baseline.

A complete pre-freeze subtractive-flattening validation was retained (600 controls/1200 trials, exact independent gate certificate), with only 5/12 template gates passing. Examination showed remaining precisely localized injections failing the strict depth gate at z~10000: e.g. aperture depth 17802.94 ppm versus frozen 17828.59 ppm, sigma 1.75 ppm. This exposed a physical units mismatch: multiplicative fractional-depth injections were being fitted in additive median-normalized residuals. Before any target search or freeze, flattening changes to raw/masked_continuum - 1. All known and control measurements/injections are rerun with new method hash; the complete subtractive archive, certificates and original values are retained and never scored. No bar, frozen depth or noise threshold changes.

The fractional rerun completed numerical checks and the same five native known signals, then stopped before any control rerun because an inline Python probe made the empty coverage/ directory appear to Numba as a namespace package named coverage. The probe is moved to a pod_tasks/ script entry point; no scientific source or dependency changes. Valid same-method native/numerical outputs are retained; controls and paired diagnostics resume after ps confirms no older workers. Failed import log and checkpoint failure are preserved.

Fractional-normalization probes on the same two preserved deep-injection controls did not materially remove their depth offsets (e.g. 17803.99 ppm became 17804.16 ppm). Thus additive-versus-fractional normalization was a valid units correction, but the hypothesis that it explains those failures was not supported. Do not claim otherwise. A separate fixed-mask control-background/transfer diagnostic is performed before freezing; all failed trials remain in the recall denominator. These descriptive diagnostics do not change a threshold or remove any failed trial.
