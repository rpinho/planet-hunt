# Frozen protocol: TIC 275488151 aperture depths

Role: measure, inject, verify. Scope is the origin of the dip's light. No FPP, planet conclusion, novelty or priority judgment. Network, if needed: public GETs only to ExoFOP-TESS attachments and MAST/TESScut, serialized, >=5 seconds between starts, exponential backoff; no other remote requests. Writes only in this directory, except an explicitly requested blocking alert. Two cores maximum, actual nice 10, BLAS/OMP threads 1. Local git commit is explicitly authorized by this task despite the generic RULES no-commit instruction.

## Gate, verbatim

- Gate R: at least 200 injections into the same file's out-of-transit cadences at random phases (drawn from times only, outside both ephemerides' windows and the EB secondary), of (L) the leak depth vector and, separately, (T) the on-target vector. Statistic: ratio R41 = depth(radius 4) / depth(radius 1). Pass if R41 > 2 at >= 3 sigma in >= 80% of L injections and in <= 5% of T injections. If Gate R fails, Bar A is UNSCORED; do not stack the real in-transit cadences for it.

## Bars, verbatim

- Bar A (aperture growth). On the real data at the EB ephemeris, R41 > 2 at >= 3 sigma. If it passes, the depth pattern favours leaked light over an on-target signal. If R41 is consistent with the T vector within 2 sigma, report "depth flat with radius, favours on target or another source inside radius 1".
- Bar E (which ephemeris, descriptive unless powered). Delta chi2 between the EB and CTOI ephemerides in the radius-2 aperture; calibrate the threshold on 200 injections of each ephemeris into the real out-of-transit flux and report the false-preference rate. Score it only if correct preference >= 80% and false preference <= 5%.
- Bar S (secondary, descriptive unless powered). Depth at EB phase 0.5007 in the radius-4 aperture against the L prediction; score only if the expected z >= 3.

## Photometry and errors

Use documented normalized LC2_AP1–AP4, 1-based columns 6,13,20,27; errors ELC2 columns 7,14,21,28; flags columns 8,15,22,29. Retain only flag==0, finite positive flux and finite positive error. The zero-flag rule rejects all documented TESS/DIAmante quality bits. No clipping, detrending choice, or aperture adjustment after flux. Use common accepted cadences for cross-aperture Gate R and A; radius-specific acceptance for E/S. LC1 is not an alternate scored reduction.

For each event: in |dt|<=0.105 d, out [-0.504,-0.252] and [+0.252,+0.504] d. Require >=3 in and >=3 out on each side. Weighted least-squares linear flux baseline from out cadences. Depth is the unweighted arithmetic mean of 1-flux/baseline in the in-window. Covariance propagates in-window noise and baseline uncertainty with first derivatives; local out-residual correlations supply cross-aperture covariance, with per-radius scatter at least its documented error scale. Stack events by inverse marginal variance in each radius. Inflate marginal errors by sqrt(max(1,event chi2/(N-1))); scale covariance by the corresponding factors, never deflate. Preserve event depths, covariance, counts, weights, event centres and errors for independent recomputation. Missing/failed trials count against their requested denominator; never retry on flux.

R41=d4/d1, requiring d1>0 and finite covariance. Delta-method sigma_R uses the full stacked covariance and gradient (-d4/d1^2,1/d1) on radii (1,4). The criterion is R41>2 and (R41-2)/sigma_R>=3. Report the ratio's denominator significance as a limitation when small. T-consistency means |R41-T4/T1|<=2 sigma_R; vector residuals are descriptive. No alternative ratio significance is substituted after the gate.

## Injection design and order

Seed 2026110236. Draw exactly 200 uniform phase shifts on [0,P_EB) for R, paired for L and T. Draw a separate 200 uniform shifts for E, paired between its two injected ephemerides. Save every phase and cadence mask from times only BEFORE reading DIAmante flux. The OOT pool excludes EB primary full phase width 0.1530, secondary width 0.1384 at phase 0.5007, and CTOI ±0.105 d, each padded by half the median cadence. Both injected in-windows and all fitted baseline cadences must lie in this pool. Masked cadences are absent, not interpolated or replaced. Random-phase trains may therefore have fewer events; retain them and report event denominators. Inject multiplicative box dimming of the L or T vector in ±0.105 d at shifted EB event centres, on original OOT flux. This tests the prescribed mean-window depth statistic, not eclipse-shape recovery. No actual primary stacks for A unless the completed R gate passes.

R first. Save 200 per-radius uninjected OOT stack uncertainties at the same R phases. Expected secondary z is predicted secondary radius-4 depth divided by the median of those radius-4 errors, computed before measuring the true secondary. S is scored only if this expected z>=3. In all cases report secondary depth/error, observed z and (measured-predicted)/error; no additional invented pass bar.

E: inject a 558 ppm box at each of the two fixed ephemerides plus the same random shift, separately, on OOT radius-2 flux. Thus power is conditional on the published radius-2 amplitude, explicitly not a fitted injection amplitude. At both candidate ephemerides use identical cadences in the union event support, ±0.60 d about the midpoint of paired EB/CTOI event centres. Profile an intercept and slope per event and one shared nonnegative box depth, weighted by documented errors with local OOT residual scatter never smaller than formal. Delta chi2=chi2_CTOI-chi2_EB (positive favours EB). Threshold EB=max(0,the 190th sorted delta under CTOI injections); threshold CTOI=min(0,the 11th sorted delta under EB injections). Strict >/< controls empirical opposite-ephemeris preferences at <=10/200 each. These are in-sample calibration rates, not held-out validation. Both correct preferences must be >=160/200 and both false preferences <=10/200 for E to score. Otherwise real E is descriptive. Real chi2 uses both ephemerides' union primary support, even if R fails; it cannot unblind A's radius-1,3,4 primary depths.
