This bundle preserves the long ExoFOP note on TIC 275488151.01 and its small supporting results, with one provenance row for every number in NOTE.md. The data sources are MAST Kepler/TESS, the public DIAmante light curve and validation report on ExoFOP by M. Montalto, and the Villanova Kepler EB Catalog. The nearby eclipsing-binary attribution is unresolved, the work is unrefereed, and no FPP was computed.

From this directory run `PYTHONDONTWRITEBYTECODE=1 python3 verify_bundle.py`, then `PYTHONDONTWRITEBYTECODE=1 python3 planets_r29_1102/verify.py`; both use only Python's standard library and the bundled files. The original job verifiers are retained as each job's `verify.py` (the round-29 verifier is an explicitly marked packaging addition). To rerun a full original audit, restore its omitted inputs and source git history, install its scientific dependencies, enter that job directory and run `nice -n 10 python3 verify.py` (rounds 27/28 accept `.` as the results root); the missing inputs and scrubbed historical hashes are explained in PACKAGING.md. The portable bundle check verifies note bytes, source mappings, derived arithmetic and file integrity; it does not repeat the photometric measurements.
