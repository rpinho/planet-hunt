# Frozen protocol — planets_r31_1102

A local power-gated test of the supplied post-hoc leak hypothesis, with a roughly 3 h time box. r30's aperture depths and noise levels are already seen; its per-pixel difference images are not. No r30 difference-image file will be opened. No r31 real difference image will be formed unless the power gate passes. No novelty, planet, or FPP claim.

## Bars, verbatim

- Bar 1, leak. On the real data, b > 0 at >= 5 sigma and b/b0 within 3 sigma of 1.
- Bar 2, target. a's 95% upper limit is below 279 ppm, and a is below 3 sigma.
- Attribution only if the power gate passes and Bars 1 and 2 pass. Otherwise report the outcome per bar. A pass means the CTOI signal is attributed to KIC 10014830 (a nearby eclipsing binary); it is not a statement about any planet and no FPP is computed.

## Four requirements, frozen before any pixel difference image

1. Sector usability from headers and PRF geometry only: drop a sector if either star's position falls outside the illuminated science area (columns 45-2092, rows 1-2048) or within 2 px of its edge. Record the list.
2. Out-of-eclipse mask from the Villanova eclipse widths (primary 0.1530, secondary 0.1384 in phase) plus 0.05 in phase on each side, for both the EB and CTOI ephemerides.
3. Model, per sector, on every cutout pixel: in-minus-out eclipse difference at the EB ephemeris = a * PRF_target + b * PRF_EB + per-pixel constant background term, pooled over sectors by weighted least squares with per-pixel noise from out-of-eclipse cadences. Report b as the ratio to the prediction b0 = Kepler EB fractional depth x EB flux (Tmag), and a as an on-target fractional depth.
4. Power gate, run on real out-of-eclipse cadences only, at random phases away from both ephemerides' windows (at least 200 trials per arm, frozen seed): (i) inject the EB leak at b0 and no target signal, then require recovery of b > 0 at >= 5 sigma in >= 90% of trials and a's 95% upper limit below 279 ppm (half the CTOI depth) in >= 90%; (ii) inject 558 ppm on the target and nothing at the EB, then require b >= 5 sigma in <= 5% of trials and a detected at >= 3 sigma in >= 80%. If either arm fails, write POWER_FAIL, stop before forming any real difference image, and report.

## Flux scale, constant backgrounds, and WLS

Use Tmag EB/target flux ratio R=10^[-0.4*(13.838-11.2155)]=0.08933054837332963. The Kepler window depth is inherited dK=0.42712322107786777 (419 primary events, 17 quarters), fixed before flux here. Kepler input and saved-output hashes are retained. For each sector estimate target flux F_s using **only** its broad-mask OOT mean pixel image: WLS fit that image to r30's complete finite-Tmag catalogue scene template (units of target flux) plus a spatially uniform background. Weights are inverse OOT sample pixel variances. The scene includes the target and EB with their Tmag ratios; do not fit their relative fluxes from eclipses. F_s must be positive or gate trials fail. The b0_s prediction is dK*R*F_s e-/s. This OOT calibration avoids imposing an unverified absolute instrumental Tmag zeropoint. Calibration, Tmag/color and Kepler-depth uncertainties are not marginalized; report this limitation.

The per-pixel constant background is a temporal nuisance c_{s,event,pixel} in the full cadence model. It is estimated from local OOT cadences and eliminated by an in-minus-out contrast. A separate freely adjustable constant for each pixel of a single difference image would make a and b unidentifiable; no such saturated model is fitted. Include one additional spatially uniform difference-background nuisance per sector to absorb coherent additive offsets.

For each predicted/injected event within the actual sector span, select in points |t-epoch|<=0.126 d. Baseline points must be original broad-mask OOT, within +/-P/2 of that epoch, and farther than 0.126+0.05*P d from the trial/real primary. Require >=3 in and >=3 out on each side of the event. Fit a constant per pixel on that event's OOT points: D_event=mean(in)-mean(out). Its variance is the sector's OOT sample pixel variance times (1/n_in+1/n_out); OOT variance includes temporal variability and is measured before injections. Aggregate events per pixel by inverse variance, tracking covariance from any reused baseline cadence through the final linear contrast coefficients: Var(D_s,p)=sigma2_OOT,s,p * sum_t c_s,p,t^2. No empirical error deflation, clipping, trend tuning, or selection by recovered signal. Report event/cadence counts. Cadence correlations are not assumed independently validated; random-phase gate tests the same data's nonwhite artifacts.

Adopt positive eclipse depths a and r=b/b0, so the equivalent explicit signed model is **D_s,p = -a F_s PRF_target,s,p - r b0_s PRF_EB,s,p + gamma_s**. This makes the negative in-minus-out eclipse sign explicit while preserving the requested positive b/depth decisions. a and r are common to all retained sectors; gamma_s is a sector nuisance. WLS normal equations pool every sector/pixel, profiling gamma_s. Formal covariance is inverse profiled normal matrix, multiplied by max(1,chi2/(Npixels-Nparameters)) for residual lack of fit. Per-sector fits use the identical rule. No prior or positivity constraint on either fitted component. Report a in ppm and r dimensionless; per-sector physical b_s=r*b0_s is also retained.

Use signed z values. 95% one-sided upper limit U_a=max(0,a)+1.6448536269514722*sigma_a. Bar 1: r>0, r/sigma_r>=5 and |r-1|<=3*sigma_r. Bar 2: U_a<279e-6 and a/sigma_a<3. These inequalities are also used in the gate (target false-EB detection uses r/sigma_r>=5). Equality passes >= tests; strict upper-limit tests remain strict.

## Gate design and stop rule

Exactly **200 trials in each arm**, seed **311102**, NumPy default_rng (PCG64). Each trial pools all 8 sectors. Both arms share its phase vectors, giving matched backgrounds; this dependence is disclosed. For each sector/trial draw uniform primary phase on [0,1) relative to T_EB and reject phases whose predicted primary centers within the sector span overlap **either** original ephemeris's broad exclusion windows. Rejection is based only on TIME/ephemerides before any recovery; cap at 100000 draws and count an impossible phase as a failed trial. Generate and save all phases before reading any FLUX. Do not redraw for cadence gaps, missing events, or a failed recovery. Actual gate input cadences are strictly original OOT for both ephemerides. In windows may be truncated by the original mask; save actual n_in/out and injected point counts. The real fit, if authorized by passing power, uses the same primary window on real in-eclipse data and the same broad-mask baseline.

EB arm injects -box(t)*b0_s*PRF_EB; target arm injects -box(t)*558e-6*F_s*PRF_target. Both are additive on actual OOT data. The identical linear contrast may be applied distributively to data and cadence-level injected PRF term to avoid 400 full cube copies; validate equivalence to an explicitly injected cube before recovery, record its maximum error. This is not injection into a preformed real eclipse difference image. No r30 difference image is read, no real EB/CTOI contrast is evaluated during the gate. Save phase/mask audits, component estimates, covariance, z, limits, WLS sufficient statistics and invalid-trial reasons.

All 200 trials count in each denominator. EB arm separately requires >=180/200 with positive >=5-sigma r and >=180/200 with U_a<279 ppm. Target arm requires <=10/200 false EB >=5-sigma detections and >=160/200 positive target >=3-sigma detections. Any invalid trial fails each desired recovery/upper-limit test; in target false-positive fraction count invalid fits conservatively as false positives. No early stopping before both complete arms. Any failed requirement => write **POWER_FAIL**, bars **UNSCORED**, stop before any real difference image. Do not produce real per-sector a/b, residuals, CTOI fits or 14-15 fits on that branch; explicitly list them as withheld by the gate.

If power passes, save the gate first, then form the EB real difference images and simultaneous pooled fit; score Bars 1 and 2. Also form real CTOI-ephemeris fits, and EB and CTOI fits restricted to sectors 14-15; save per-sector a/r/b, residual images and their variances. Inspect/export residual images only then. DIAmante's documented aperture is contextual; do not change this method to match it.
