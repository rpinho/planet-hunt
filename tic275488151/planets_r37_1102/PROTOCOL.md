# Frozen protocol: TESS-era EB template versus CTOI box

Role: measure, inject, verify. No network, uploads, messages to others, FPP, planet statement or novelty/priority judgment. Write only in this job directory. Explicit user authorization permits this local freeze commit despite the generic RULES no-commit instruction. Single process at actual nice 10 with BLAS/OMP and other numerical thread pools fixed to 1, maximum two cores. Read-only sources: r36, r30, r32. PRIOR_ART.md was written first.

## Gate, verbatim

- Gate C: at least 200 injections of each model into the radius-2 out-of-transit cadences with paired random phase shifts, using r36's timestamp-only supplement design (or a new one drawn from times only, frozen before flux): M_EB at a0, M_CTOI at 558 ppm. Statistic delta chi2 = chi2(M_CTOI) - chi2(M_EB), threshold 0. Pass if each model is preferred when it is the injected one in >= 80% of trials and the other is falsely preferred in <= 5%. If Gate C fails, Bar T is UNSCORED.

## Bars, verbatim

- Bar T (timing and shape). On the real radius-2 data, delta chi2 > 0 favours M_EB; delta chi2 < 0 favours M_CTOI. Report which, with its value.
- Bar F (amplitude). The fitted M_EB amplitude a/a0 is within 3 sigma of 1, with sigma from the injection scatter.
- Attribution of the CTOI dip to KIC 10014830's leaked light only if Gate C passes, Bar T favours M_EB and Bar F passes. If Bar T favours M_CTOI, report "the dip does not follow the EB's TESS-era eclipses", which counts against the NEB reading.

## Model definitions fixed without new target flux

BTJD=BJD-2457000. M_EB is h_EB(t)=1-interp_periodic((t-TE-offset_sector-shift)/PE, phase, flux) from r36 outputs/kepler_template.npz, with the entire folded shape retained and no width/truncation/shape fit. PE=3.0305267 d; TE=2454967.124438-2457000 d. Both sector offsets come from the separate fits in r36 outputs/EB_TESS.json (both -0.038 d). Do not use the combined -0.036 d fit or multiply the shape by the EB-aperture amplitude 0.97; the fitted target amplitude absorbs its scale. Sector membership is taken from r30 aperture_manifest.json TSTART/TSTOP timestamps and frozen in DESIGN.npz.

M_EB fractional dimming is a*h_EB, with a free nonnegative amplitude as in r36 Bar E. Let D_template be the continuous mean of h_EB over [-0.105,+0.105] d about zero phase, evaluated by trapezoidal integration including every interpolation knot and the exact endpoints. Fix a0=(r36 PLAN.json L[1])/D_template. This convention gives the specified 325.3605 ppm mean-window model depth, without target flux or cadence sampling, and retains template baseline structure. Record the small difference from r36's direct event-stack Kepler mean depth. No uncertainties in PRF/shape/timing are fitted. M_CTOI is h_CTOI=1 within +/-0.105 d at PC=3.02553 d, TC=2458682.5504-2457000 d, otherwise 0, with free nonnegative fractional box amplitude.

Use r36 acceptance: LC2 flux/error/flag columns (zero-based 5/6/7,12/13/14,19/20/21), flag=0, finite positive flux and error. No clipping. Exactly reproduce r36 Bar E support: pair original unshifted EB and CTOI cycle centres, with k=-3,...,22 and the EB cycle nearest TC as reference; apply the paired shift to both centres. Per pair retain |t-midpoint|<=0.60 d. Original +/-0.105 d EB and CTOI box masks define event eligibility (>=12 total, >=3 in each box, >=3 union-box-out cadences on each side). These timestamp tests, original support centres and union-box-out scatter-estimation mask remain identical to r36. The EB model itself uses the shifted TESS-era template. Both candidate models use exactly the same accepted rows, weights and per-event intercept/slope projection; broad EB wings are retained in the fit. The r36 union-box-out scatter estimate is retained even where EB wings extend into it; this is a declared limitation, not an adaptive change.

Per event: fit a weighted linear baseline on original union-box-out rows to estimate scatter; inflate errors by sqrt(max(1, residual chi2/(Nout-2))). Normalize flux and errors by median out flux, then project both templates and flux against the same weighted intercept and slope on all support rows. Sum hh,hy,yy across events. a=max(0,-hy/hh); gain=hy^2/hh if hy<0 and hh>0, else 0; chi2=yy-gain. Delta= gain_EB-gain_CTOI. Retain per-event normal equations and totals for independent verification. The old two-box profile must reproduce r36 real Bar E before the new real-model comparison is interpreted.

## Injection and ordering

Reuse exactly the 200 E shifts in r36 outputs/supplement_phases.json; its generation is timestamp-only and predates this job's flux. Reuse outputs/time_design.npz clean OOT mask, which excludes full catalogued EB primary/secondary widths and CTOI boxes with half-cadence padding. It is the r36 mask, not retrospectively retimed. Save hashes, phases, timestamps, masks, model constants, normalization and source metadata in a local design commit BEFORE numeric flux read. Synthetic linear baselines with both shapes test fitting before flux.

For each phase, separately multiply original accepted OOT flux by (1-a0*h_EB_shift) and (1-0.000558*h_CTOI_shift), evaluating models on the same OOT timestamps. Errors stay as supplied, as in r36. Fit each injected data set with both shifted models on identical per-trial support. Save counts of materially injected rows (h_EB absolute dimming >1e-12, CTOI in-box), fit-valid trials, events and all 200 requested denominators. Missing/no-information fits and ties count as neither correct nor false; they cannot be retried based on flux. If fewer than 200 actual injections per type occur, Gate C fails its minimum. Strict delta>0 prefers EB, delta<0 prefers CTOI; threshold remains exactly zero without calibration. Require >=160/200 correct and <=10/200 opposite in EACH type. These are separate conditions even though at zero threshold without ties they are complements.

Before real new-model fits, compute sigma for Bar F as sample standard deviation (ddof=1) of fitted a/a0 from valid EB injections, without bias correction, clipping or selection on preference. Save its count, mean, bias and scatter. If fewer than 2 valid fits, F is UNSCORED. Otherwise F passes iff abs(real a/a0-1)<=3*sigma, even if Gate C fails. Report F separately; no attribution without all three required conditions. If Gate C fails, report the real sign/value descriptively with Bar T UNSCORED; the requested CTOI-preference wording is explicitly descriptive in that case.

Descriptive comparisons: same real profile in radii 1 and 3; combined and sector 14/15 fits for all three radii, using each radius's own r36 acceptance. Radius-2 EB secondary: r36 local linear mean-window extract/stack, +/-0.105 d at TE+offset_sector+0.5007*PE, out [-0.504,-0.252],[0.252,0.504], >=3 in/left/right, propagate noise and baseline covariance, inverse-variance event stack with event chi2 inflation >=1. Report against r36 PLAN.json secondary[1] (~144 ppm), including each sector. No secondary pass criterion or extra attribution bar.
